# Find worst tolerance

準備中  
FreeCAD macro

## 概要

トレランス値ワースト要素(Vertex, Edge, Face)を探して選択状態にします

## 目的

## インストール方法

- アドインマネージャに対応予定
- 設定にリポジトリ追加

### 動作確認環境

- FreeCAD v1.1.1
- Windows10 64bit

## 操作手順

- ワースト・トレラントの各要素（頂点、エッジ、面）を探す
  - FreeCADのトレランス初期値を超える要素を選択状態にする（選択色に変化）
  - レポートビューに結果表示
